Slash Vice is a browser cover-art studio that turns any photo and a caption into GTA-poster-style multi-panel cover art — slanted panels, sunset and neon colour grades, bold gradient lettering — and exports it as a PNG in three post sizes (1080×1080, 1080×1350, 1920×1080). It runs fully offline from its own static files: photos never leave the machine. Open `app/index.html` in a desktop browser, drop in a photo, pick a layout and grade, edit the lettering, export.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
